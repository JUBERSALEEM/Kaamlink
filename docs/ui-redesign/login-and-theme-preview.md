### What changed

- **Continue with Google is explained, not silently greyed out.** It stays disabled
  because there is no Google Cloud OAuth client and no server-side ID-token
  verification/account linking. The note now points users to the free email link
  or phone verification instead.
- **Email magic link is the primary CTA.** The app calls Supabase GoTrue
  `POST /auth/v1/otp`, the email link opens `kaamlink://auth-callback`, and the
  verified Supabase access token is exchanged at
  `POST /api/v1/auth/email/exchange` for KaamLink's own JWT + refresh token pair.
  See [`docs/email-magic-link-setup.md`](../email-magic-link-setup.md).
- **Terms and Conditions is a real `CheckBox`.** Both email magic-link and phone
  OTP actions are blocked until it is ticked. Acceptance is persisted so the
  callback still works after the device switches to the email app and back.
- **Aurora palette:** indigo/violet brand gradients, cyan/mint accents, lavender
  clay surfaces in light mode and rich midnight-violet surfaces in dusk mode. The
  dark theme is chromatic, not black/AMOLED. All 55 static contrast checks still
  pass.
- **Latest rounded shapes:** 24dp buttons, 28dp cards/banners, 22dp inset fields,
  pill icon tiles, and a refreshed clay shadow ramp. Day/Dusk uses native
  `Button`s with compiled palette dictionaries, so the toggle is clickable.
- **Crash hardening remains:** iterative cycle-safe clay-shadow refresh, dispatcher
  deferred refresh, observed async page initialization, malformed-JSON handling
  in session refresh, and explicit tap routing.
- Offline / no-internet / server-not-configured / invalid-link / rate-limit states
  have localized EN/AR copy.

## Connectivity status

App-side causes remain fixed and gated: no reserved `.invalid` Release host, a
build-time public HTTPS URL, Debug-only LAN cleartext policy, a shared 15-second
timeout, one `IHttpClientFactory`-managed auth client, and clear localized errors
for offline / no-internet / server-not-configured states. The Supabase GoTrue
client uses the same bounded timeout.

End-to-end production auth still needs a **public HTTPS backend URL** (passed with
`-p:KaamLinkApiBaseUrl=https://.../`), the Phase 06 backend migration, and a
**production SMS provider** for phone OTP. Supabase's built-in email provider is
free but rate-limited; configure **custom SMTP** before production magic-link
traffic. See
[`docs/connectivity-and-release-configuration.md`](../connectivity-and-release-configuration.md)
and [`docs/email-magic-link-setup.md`](../email-magic-link-setup.md).
