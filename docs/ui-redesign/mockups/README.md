# Mockup renderer

The PNGs in this folder are **rendered from a structured layout**, not generated by
an image model: every string is drawn with the app's own font (Open Sans), icons come
from the Lucide glyph font, and Arabic specimens use Noto Sans Arabic. That means the
text in a mockup is exactly the text the implementation uses, which is what makes the
mockups usable as an implementation reference.

## Regenerate

```bash
python3 -m venv /tmp/mockup-venv
/tmp/mockup-venv/bin/pip install Pillow arabic-reshaper python-bidi
/tmp/mockup-venv/bin/python docs/ui-redesign/mockups/render_mockups.py
```

Requirements:

* `Resources/Fonts/OpenSans-*.ttf` and `Resources/Fonts/lucide.ttf` (in the repo)
* `docs/ui-redesign/mockups/fonts/NotoSansArabic-*.ttf` for the Arabic specimens
  (SIL OFL 1.1 — see `fonts/NotoSansArabic-LICENSE.txt`)
* Pillow is used *without* libraqm in CI-like environments; `mockup_kit.shape()`
  falls back to `arabic-reshaper` + `python-bidi`, which produces the same joining
  behaviour the Android text stack applies natively.

## Files

| File | Purpose |
|---|---|
| `mockup_kit.py` | tokens, fonts, icons, layout primitives and components |
| `render_mockups.py` | one function per screen; `SCREENS` lists the output order |
| `*.png` | rendered screens (720 × 1560 @2×, design system sheet is taller) |

> **Historical set.** `render_mockups.py` documents the first flat design pass and
> its `02-login.png` is **not** the current login screen. The current sign-in UI is
> rendered by `tools/render-login-preview.py`, which reads the shipped
> `Colors.xaml` / `ClayDusk.xaml` palette and `AppStrings.resx` directly:

```bash
python3 -m venv /tmp/login-preview-venv
/tmp/login-preview-venv/bin/pip install Pillow
for theme in light dusk; do
  /tmp/login-preview-venv/bin/python tools/render-login-preview.py --theme "$theme" \
    --out "docs/ui-redesign/mockups/login-aurora-$theme.png"
done
/tmp/login-preview-venv/bin/python tools/render-app-icon-preview.py \
  --out docs/ui-redesign/app-icon-upgraded-preview.png
```

`login-current-*.png` are the pre-upgrade clay snapshots;
`login-upgraded-*.png` document the previous rich light / midnight-navy dark pass.
`login-aurora-*.png` are the **current Aurora Clay / Aurora Dusk** login screens with
email magic link, the sent-link state and the tickable terms checkbox. Together with
`docs/ui-redesign/app-icon-upgraded-preview.png` they are the visual references for
the shipped design. The older `*.png` files remain for design history only.

The colour values in `mockup_kit.py` belong to the historical palette; the live
palette is verified by `tools/verify-theme-contrast.py` and
`tools/verify-ui-redesign.py`, and the current login preview reads it at render
time rather than duplicating hex values.
